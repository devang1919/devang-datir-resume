# Information as a Resource

Interactive case-study app for Division B, Roll No. 077, Devang.

## Run locally

Open `index.html` in a browser. The app is a self-contained static site with no build step or external dependencies.

## Features

- Dashboard overview of the local grocery store case study
- Information needs and source classifications
- Search and filtering
- Interactive questionnaire preview
- Downloadable case study text and print-ready layout
- Responsive Apple-inspired minimalist interface
